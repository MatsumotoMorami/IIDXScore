# IIDXScore 自动迁移（推荐）

此工具适用于已安装 **IIDXScore 0.5.3**、从 IIDX33/旧 Omnimix 转到 IIDX34 AC+Omni 的电脑。它会直接写入成绩数据库并更新 DLL 同目录的 `IIDXScore.ini`；旧成绩作用域保留。不要在游戏运行时使用。

1. 退出游戏。把产生旧成绩时使用的 IIDX33 `music_omni.bin` 放入游戏根目录的 `IIDXScoreLegacy/music_omni.bin`。当前 IIDX34 的 `music_omni.bin` 不能代替旧文件。若旧索引已经在游戏根目录的 `backups` 等备份目录中，程序也会按数据库中的 SHA256 自动查找。
2. 把本压缩包中的 `IIDXScoreAutoMigrate.exe` 和 `MigrateScores.bat` 放到与 `bm2dx.dll` 同目录的**游戏根目录**。确认当前 IIDX34 AC 索引位于 `data/info/0/music_data.bin`，当前 Omni 索引位于 `data_mods` 下，且 `IIDXScore.dll` 在根目录或直属子目录中。
3. 双击 `MigrateScores.bat`。程序检查游戏已退出、DLL 版本、数据库、曲库索引和全部成绩匹配情况；缺旧索引、有未匹配成绩或目录有歧义时停止，不写成绩。检查通过后，它会先生成 `scores/IIDXScore-backup-日期时间.sqlite3` 和旧 INI 备份，再迁移成绩、更新 INI，最后在根目录写出 `IIDXScore-自动迁移报告-日期时间.json`。
4. 看到“迁移完成”后再启动游戏。若游戏里仍无旧成绩，请先核对生成的 JSON 报告和 `IIDXScore.log`。原来的数据库备份与 INI 备份不要立即删除。

自动工具会保持原有 `DatabasePath` 和 `ServerKey`，把 `MusicDatabase` 设置为当前 AC 索引，`OmniMusicDatabase` 设置为当前 IIDX34 Omni 索引，并把 `LegacyMusicDatabase` 设置为找到的旧索引。相对路径按 DLL 所在目录计算；DLL 在游戏根目录下一层时会自动写入 `../`。重复运行不会重复复制旧游玩快照，但会额外产生一份备份。

如果想先确认预计迁移数量，可以运行同一 Release 的只读 `IIDXScoreDryRun.exe`。本工具与只读试算工具不同：**双击后会正式写入数据库**。手动配置 INI 的方式见 Release 说明和 README。
